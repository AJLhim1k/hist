# Архитектурный облик Москвы в XX веке (Telegram WebApp)

Учебный исторический проект в формате интерактивной экскурсии по теме:
**«Россия и СССР в советскую эпоху (1917-1991)»**.

Команда:
- Петров Егор
- Третьяков Радомир

## Что реализовано
- Telegram-бот с кнопкой запуска WebApp (`/start`).
- Веб-приложение с логикой экскурсии:
  - таймлайн эпох,
  - остановки маршрута,
  - реализованные и нереализованные проекты,
  - блок европейских влияний,
  - социально-культурные итоги.
- Интерактивный квиз с проверкой ответов и объяснениями.
- Рейтинг участников и баллы.
- Экспорт материалов:
  - `.md` для быстрой сборки в PPT/PDF,
  - печатная HTML-версия для сохранения в PDF.
- Отдельная структурированная база содержания и источников: `content/moscow_xx_century.json`.

## Историческая точность
Проект содержит список источников и привязку фактов/вопросов к источникам.
Основная идея: не хранить факты «в коде», а в отдельном контентном JSON, чтобы быстро перепроверять и актуализировать материалы перед защитой.

## Быстрый старт
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python bot_app.py
```

После запуска:
- WebApp: `http://localhost:8080`
- Health-check: `http://localhost:8080/health`

## Настройка Telegram
В `.env`:
- `TELEGRAM_API_KEY` — токен бота от BotFather.
- `WEB_APP_URL` — публичный URL WebApp (для кнопки в Telegram).
- `SESSION_SECRET` — urlsafe-base64 ключ, декодирующийся в 32 байта.

Если `TELEGRAM_API_KEY` не задан, работает только WebApp-часть (без polling бота).

## Структура проекта
- `bot_app.py` — aiohttp + aiogram приложение.
- `db.py` — SQLite слой (пользователи, ответы квиза, рейтинг).
- `content/moscow_xx_century.json` — сценарий экскурсии, квиз, источники.
- `html_dir/index.html` — UI.
- `html_dir/static/styles.css` — стили.
- `html_dir/static/app.js` — клиентская логика.
